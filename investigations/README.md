These notes contain the raw materials and working drafts generated as part of the Legislation Subject Classification project. The current notes are focused on discovery work relating to the Find Case Law service.

The notes comprise a set of markdown documents with cross-links and index files which form a wiki. As well as viewing over github itself, a local copy of these files can be browsed using any markdown wiki tool such as [Obsidian](https://obsidian.md/). That has the advantage that sections and bullet lists can be "folded" to hide the lower level details which is very helpful when browsing the larger extracted taxonomies.

The bulk of notes here were generated with the assistance of LLM-based research agents, guided by "skills" files to support recording investigation progress using this markdown wiki format. We refer to agent enabled collections like this as a _knowledge base_ or KB. 

**Be cautious** in interpreting the raw notes. They will include LLM-powered mistakes and overzealous interpretation of findings. The accompanying report, is human authored and reviewed and is the definitive guide to the results of the investigation so far.
